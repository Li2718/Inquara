# Decisions Index

> status: current
> purpose: Provide a lightweight index of high-leverage design decisions and where they apply.

## What Belongs Here

Use this directory for a small number of high-leverage design decisions.

These docs explain:

- why a choice was made
- what trade-offs mattered
- what current docs it affects
- what kinds of future changes should trigger a re-check

## When To Read This Directory

Read decisions when:

- you already know the current rule and want to understand why it exists
- you are changing a high-leverage behavior and need to verify whether an existing decision is still valid
- you are trying to understand a cross-cutting trade-off that touches multiple current docs
